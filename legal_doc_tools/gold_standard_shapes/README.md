# Gold Standard Output Shapes

Internal QA only. These files record ideal answer structures abstracted from local course, feedback and marked-solution materials.

They are not source law, not model answers, and must not be copied into generated user answers. Their purpose is to help backend audits judge whether an output has the right shape, depth and issue discipline.

Use these files for:
- manual/live backend QA;
- rubric design;
- stress prompt scoring;
- spotting generic output.

Current shape files cover:
- Law and Medicine course-bound/no-limit essays;
- Competition Article 102 digital-platform problems;
- Land registered-priority and co-ownership/estoppel problems;
- Trusts creation, secret-trust, purpose-trust and tracing problems;
- Business/company conflicts, related-party transactions and insolvency remedies;
- Evidence admissibility and fair-trial/reliability answers;
- Public law legitimate expectation, improper purpose and HRA/proportionality answers;
- Pensions equalisation/amendment and non-financial investment problems;
- International commercial mediation Convention and process/enforcement answers.

Do not use these files for:
- answer injection;
- citation support;
- replacing RAG retrieval;
- copying wording into user-facing drafts.
